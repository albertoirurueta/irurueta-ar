== Building from source

The library can also be built locally with Maven:

[source,bash]
----
git clone git@github.com:albertoirurueta/irurueta-ar.git
cd irurueta-ar
mvn clean install
----

This requires Java 21 or later, as configured by the project's CI pipeline.
