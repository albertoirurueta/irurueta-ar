= Fundamental matrix estimation
:stem: latexmath

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

The fundamental matrix stem:[F] is a stem:[3\times 3], rank-2 matrix that encodes the epipolar geometry between
a pair of uncalibrated views: it is the only piece of information needed to constrain where a point in one
image can match in the other, without knowing anything about the cameras' intrinsic parameters.

image::epipolar/epipolar-geometry.svg[Epipolar geometry between two views,600,role=text-center]

Given a 3D world point stem:[M], its projections stem:[m] and stem:[m'] on the left and right views, the
camera centers stem:[C], stem:[C'] and stem:[M] always define a plane -- the *epipolar plane* stem:[\Pi_e].
Its intersection with each image plane is an *epipolar line* (stem:[l] on the left view, stem:[l'] on the
right), and the projection of one camera's center onto the other view is that view's *epipole* (stem:[e],
stem:[e']). As stem:[M] varies, every epipolar plane still contains the baseline stem:[CC'], so all epipolar
lines in a view pass through that view's epipole -- a pencil of lines:

image::epipolar/pencil-of-epipolar-lines.svg[Pencil of epipolar planes and lines,600,role=text-center]

== The epipolar constraint

Because stem:[m] lies on epipolar line stem:[l] and stem:[l] passes through epipole stem:[e], stem:[l \equiv [e\]_\times m], where stem:[[e\]_\times] is the skew-symmetric cross-product matrix of stem:[e]. Back-projecting
epipolar lines to the (shared) epipolar plane and forward-projecting to the other view yields the linear map

[stem]
++++
l' \equiv \left(P'^{T}\right)^{\dagger} P^{T} [e]_\times m = F m,\qquad F \equiv [e']_\times\, P' P^{\dagger}
++++

so any matched pair must satisfy the **epipolar constraint**

[stem]
++++
m'^{T} F\, m = 0
++++

stem:[F] is defined up to scale (8 DOF from stem:[3\times 3 - 1]) and, since stem:[Fe = 0] and stem:[e'^{T}F = 0], its left/right null-spaces are exactly the two epipoles -- forcing stem:[\det(F) = 0] and leaving 7 true
degrees of freedom. Given the SVD stem:[F = U S V^{T}], the epipoles are recovered directly as the singular
vectors of the zero singular value: stem:[e = v_3] (last column of stem:[V]), stem:[e' = u_3] (last column of
stem:[U]) xref:reference.adoc#ref-thesis[Irurueta, PhD thesis] xref:attachment$irurueta-phd-thesis.pdf#page=103[&sect;3.2.1]
(`FundamentalMatrix.computeEpipoles()`, `getLeftEpipole()`/`getRightEpipole()`). When the pair of cameras
stem:[P], stem:[P'] is already known, `new FundamentalMatrix(leftCamera, rightCamera)` computes stem:[F]
directly from `stem:[F = [e'\]_\times P'P^{\dagger}]`.

== Linear estimation and the 8-point algorithm

Expanding the constraint for inhomogeneous coordinates gives one linear equation per correspondence in the 9
unknowns of stem:[F] stacked as a vector stem:[f]:

[stem]
++++
\left(x x',\ y x',\ x',\ x y',\ y y',\ y',\ x,\ y,\ 1\right)\, f = 0 \;\Longrightarrow\; A f = 0
++++

With 8 or more correspondences, stem:[f] is the right singular vector of stem:[A] for its smallest singular
value (exact null-space for exactly 8 points, LMSE fit for more). The resulting matrix is not guaranteed to
have rank 2, so the *8-point algorithm* enforces it by zeroing the smallest singular value of stem:[F]'s own
SVD: if stem:[F = U\,\mathrm{diag}(s_1,s_2,s_3)\,V^{T}], the closest rank-2 matrix in Frobenius norm is
stem:[F' = U\,\mathrm{diag}(s_1,s_2,0)\,V^{T}]. Point coordinates are normalized beforehand (centroid at the
origin, RMS distance stem:[\sqrt2]) to keep the linear system well conditioned
xref:reference.adoc#ref-thesis[Irurueta, PhD thesis] xref:attachment$irurueta-phd-thesis.pdf#page=108[&sect;3.2.2.1], matching the normalized-DLT practice in
Hartley & Zisserman xref:reference.adoc#ref-hartley-zisserman-2003[Hartley & Zisserman, 2003] &sect;11.2.

Maps to `com.irurueta.ar.epipolar.estimators.EightPointsFundamentalMatrixEstimator` (`setPointsNormalized`
toggles normalization).

== The 7-point algorithm

Seven correspondences make stem:[A] a stem:[7\times 9] matrix whose null-space has dimension 2, spanned by
stem:[F'] and stem:[F''] (the two smallest-singular-value right singular vectors). The true stem:[F] is some
combination stem:[F = F' + \alpha F'']; enforcing the rank-2 constraint stem:[\det(F' + \alpha F'') = 0] gives a
cubic in stem:[\alpha] whose real root(s) are found via the companion-matrix/eigenvalue technique. One real
root means a unique, non-degenerate solution; three distinct real roots signal a geometrically degenerate
configuration (e.g. all points near-coplanar, or the two camera centers too close together)
xref:reference.adoc#ref-thesis[Irurueta, PhD thesis] xref:attachment$irurueta-phd-thesis.pdf#page=110[&sect;3.2.2.2].

Maps to `SevenPointsFundamentalMatrixEstimator` (`estimateAll()` returns every real solution; `estimate()`
picks the single valid one).

Two additional non-robust variants exist for restricted motions: `AffineFundamentalMatrixEstimator` (for
affine cameras) and `PlanarFundamentalMatrixEstimator` (when all points lie on a common plane, using the
plane-induced homography relation stem:[F = [e'\]_\times H]).

== Robust estimation

With many, possibly mismatched correspondences, a robust wrapper repeatedly draws a minimal sample (7 or 8
points), fits stem:[F] with the corresponding non-robust estimator, and scores the fit by the *epipolar
distance* of every correspondence to its generated epipolar line:

[stem]
++++
d(m', l') = \frac{\left|m'^{T} l'\right|}{\sqrt{l'^{2}_1 + l'^{2}_2}},\qquad l' = F m
++++

This is exactly the two-tier pattern described in xref:estimation/robust-vs-nonrobust.adoc[]: pick
`FundamentalMatrixEstimatorMethod.SEVEN_POINTS_ALGORITHM` or `EIGHT_POINTS_ALGORITHM` as the inner non-robust
solver, and `RobustEstimatorMethod.{RANSAC,LMEDS,MSAC,PROSAC,PROMEDS}` as the outlier-rejection strategy. A
threshold of 1-2 pixels on stem:[d(m',l')] works well in practice
xref:reference.adoc#ref-thesis[Irurueta, PhD thesis] xref:attachment$irurueta-phd-thesis.pdf#page=116[&sect;3.2.3].

Maps to `{RANSAC,LMedS,MSAC,PROSAC,PROMedS}FundamentalMatrixRobustEstimator`, all subclasses of the abstract
`FundamentalMatrixRobustEstimator` (factory: `FundamentalMatrixRobustEstimator.create(...)`).

== Example

[source,java]
----
// Exact 7-point solve (7 correspondences)
var sevenPoint = new SevenPointsFundamentalMatrixEstimator(leftPoints, rightPoints);
List<FundamentalMatrix> candidates = sevenPoint.estimateAll(); // 1 or 3 real solutions

// Robust estimation over many (possibly wrong) correspondences
var ransac = (RANSACFundamentalMatrixRobustEstimator) FundamentalMatrixRobustEstimator.create(
        leftPoints, rightPoints, RobustEstimatorMethod.RANSAC);
ransac.setThreshold(1.0); // pixels of epipolar distance
FundamentalMatrix fundamentalMatrix = ransac.estimate();

Point2D leftEpipole = fundamentalMatrix.getLeftEpipole();
Point2D rightEpipole = fundamentalMatrix.getRightEpipole();
----
